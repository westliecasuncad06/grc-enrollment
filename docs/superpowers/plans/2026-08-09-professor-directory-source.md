# Professor Directory Source Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Synchronize every professor from the supplied Markdown list into an Active local Faculty account and rewrite the list with each account email and department.

**Architecture:** Extend the existing local-only workbook faculty seeder with a parser and deterministic account upsert for the Markdown source. Keep account creation in a database transaction, then write the refreshed Markdown directory and existing local account report after the database transaction succeeds.

**Tech Stack:** Laravel 12, Eloquent, PHPUnit, Laravel filesystem, existing Faculty identity enums.

## Global Constraints

- Process only in `local` or `testing` environments.
- Never commit the supplied Professor Department List source or generated local report.
- Preserve raw department labels; only the four college codes receive a `college` scope.
- No password is rendered in the Markdown list; local Faculty password remains `password`.
